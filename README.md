# EriK Launcher

O launcher do Erik Carr para jogar os mods de Among Us: abre o Among Us original com os mods que o Erik define, sem instalar mod nenhum na mão. Tem no **PC (Windows)** e no **celular (Android)**.

**Baixar:** https://erikcarr.github.io/eriklauncher/ (ou a versão mais nova em [Releases](https://github.com/ErikCarr/eriklauncher/releases)).

Este repositório guarda só as versões publicadas (o `.exe` do PC e o `.apk` do celular, em Releases), a página de download e o `eriklauncher.json`, que o app lê para avisar quando tem versão nova e para achar o servidor do Erik. O código fica em outro lugar.

## Como usar

1. **PC:** baixe o `EriKLauncher-v….exe` e abra (o Windows pode avisar — **Mais informações → Executar assim mesmo**). **Celular:** instale o `EriKLauncher-Celular-v….apk`.
2. Se pedir um **código de acesso**, use o que o Erik te passou (só na primeira vez).
3. Quando o Erik abrir uma sessão, clique em **JOGAR**. O launcher abre o Among Us com os mods da sessão; fechou, tudo volta ao normal.

Passo a passo com imagens: https://erikcarr.github.io/eriklauncher/tutorial.html
